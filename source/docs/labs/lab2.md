# Лабораторная работа №2

## Описание задачи
В этой лабораторной работе необходимо реализовать набор функций для работы с NumPy, pandas, matplotlib и seaborn. По заданию требовалось создавать массивы и матрицы, выполнять векторные и матричные операции, загружать данные из CSV, считывать основные статистики, и строить три типа графиков: гистограмму, тепловую карту корреляции и линейный график. Также затем необходимо пройти все 17 тестов.

## Как я решил задачу
Я сразу же приступил к реализации функций в файле main.py. Для операций с массивами применял такие функции: np.arange, np.random.rand, методы reshape и transpose для изменения формы и транспонирования. Векторные и матричные вычисления выполнял средствами NumPy. Для загрузки данных из CSV использовал pandas.read_csv, а затем перевёл таблицу в массив NumPy. Статистические показатели вычислял через соответствующие функции NumPy, приводя каждое значение к типу float, чтобы избежать лишних проблем с типами данных. Для визуализации гистограмм и линейных графиков использовал matplotlib.pyplot, а seaborn — для построения тепловой карты корреляции.

После этого я провел тесты и убедился, что все работает.

## Нюансы при решении
Все три функции визуализации сохраняют изображения в директорию plots/. Важно вызывать plt.close() после сохранения, чтобы избежать наложения графиков при повторном запуске тестов. Также для избежания проблем с аннотацией результаты некоторых функций, например np.dot(), можно обернуть во float.
